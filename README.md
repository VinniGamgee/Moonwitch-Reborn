## Sobre

O Moonwitch é um emulador voltado para dispositivos com GPU Qualcomm Adreno, com foco em desempenho e compatibilidade nesse hardware.

## Build

A build estável mais recente está no workflow
[`build-android.yml`](https://github.com/VinniGamgee/Moonwitch-Reborn/actions/workflows/build-android.yml).
Baixe o artefato da execução mais recente na aba **Actions**. O pipeline Android usa uma build Release padrão.

## Créditos

O Moonwitch é um fork do [Eden Emulator](https://eden-emu.dev). Todo o crédito pelo trabalho original vai para a equipe e os colaboradores do Eden.

As correções de memória da GPU/NCE para a grama de Zelda: Tears of the Kingdom e
as melhorias de sincronização portadas do Lemon 1.2.0 são de autoria de
**[Ghael-V / Lemon Project](https://github.com/Ghael-V/Lemon-Project)**.
Todo o crédito por essas correções pertence ao desenvolvedor e ao Lemon Project;
o Moonwitch realiza sua integração. [Commits de origem e atribuições](docs/LEMON_PROJECT_PORTS.md).
